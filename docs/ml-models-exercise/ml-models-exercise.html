Create recipes and workflows for each model

# Create a recipe for all models
# Outcome is Y, all other variables are predictors
base_recipe <- recipe(Y ~ ., data = d1) %>%
  # Create dummy variables for categorical predictors
  step_dummy(all_nominal_predictors()) %>%
  # Remove predictors with zero variance
  step_zv(all_predictors()) %>%
  # Normalize numeric predictors
  step_normalize(all_numeric_predictors())
# Specify a linear regression model
lm_spec <- linear_reg() %>%
  set_engine("lm")

# Specify a LASSO regression model with penalty fixed at 0.1
lasso_spec <- linear_reg(
  penalty = 0.1,
  mixture = 1
) %>%
  set_engine("glmnet")

# Specify a random forest model with default tuning settings
# The seed is passed into the engine for reproducibility
rf_spec <- rand_forest() %>%
  set_engine("ranger", seed = rngseed) %>%
  set_mode("regression")
# Create workflow for the linear model
lm_wf <- workflow() %>%
  add_recipe(base_recipe) %>%
  add_model(lm_spec)

# Create workflow for the LASSO model
lasso_wf <- workflow() %>%
  add_recipe(base_recipe) %>%
  add_model(lasso_spec)

# Create workflow for the random forest model
rf_wf <- workflow() %>%
  add_recipe(base_recipe) %>%
  add_model(rf_spec)

Fit the models

# Fit the linear model to the full dataset

Overall, the results show that model flexibility can improve performance, but proper evaluation matters. In the initial full-data fit, the random forest produced predictions closest to the observed values, while the LASSO and linear model performed almost identically. The LASSO tuning results showed that very small penalty values gave the lowest RMSE, which makes sense because a small penalty makes the LASSO behave similarly to ordinary linear regression. As the penalty increased, RMSE rose because stronger regularization shrank the coefficients too much and reduced predictive accuracy. For the random forest, better performance was observed when more features were considered at each split and smaller node sizes were allowed, suggesting that a more flexible tree structure fit the data better. However, the tuning results from apparent resampling were overly optimistic because the same data were used for both training and evaluation, which is why cross-validation is essential for reliable model assessment. The cross-validation results provided more realistic estimates of predictive performance and showed that the random forest remained the best-performing model overall.
