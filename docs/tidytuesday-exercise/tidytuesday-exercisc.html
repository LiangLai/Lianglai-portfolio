Tidy Tuesday Exercise

Introduction

This week’s Tidy Tuesday dataset comes from Te Papa Tongarewa (The Museum of New Zealand) and contains logbook entries of seabird sightings near New Zealand from 1969 to 1990. Each record corresponds to a 10-minute observation window from a ship, including the bird species observed, their behaviors, and environmental conditions such as wind speed, sea state, and season.

Question: Can environmental conditions (season, wind speed class, sea state class, and latitude) predict whether a Wandering Albatross will be observed during a given 10-minute ship survey?

We want to choose The Wandering Albatross as our target species for this exercise because it has the highest number of observation records across all surveys (11296 records when all plumage/age variants are combined).

Modeling

Train / Test Split

# 75% training, 25% test, stratified by outcome to preserve class balance
set.seed(rngseed)
split <- initial_split(model_data,
                       prop   = 0.75,
                       strata = albatross_present)

train_data <- training(split)
test_data  <- testing(split)

Cross-Validation Setup

# 5-fold CV on training data, stratified by outcome
set.seed(rngseed)
cv_folds <- vfold_cv(train_data, v      = 5, strata = albatross_present)

Preprocessing Recipe

# A single shared recipe is applied to all three models for a fair comparison
albatross_recipe <- recipe(albatross_present ~ ., data = train_data) %>%
  # Encode the season factor as dummy variables
  # (required for logistic regression and LASSO)
  step_dummy(season) %>%
  # Normalize all numeric predictors to mean = 0, sd = 1
  # This is especially important for LASSO, which penalizes raw coefficient size
  step_normalize(all_numeric_predictors()) %>%
  # Remove near-zero variance predictors that may arise after dummy encoding
  step_nzv(all_predictors())

Model 1: Logistic Regression

# Logistic regression with penalty = 0 (no regularization)
# Using glmnet engine to keep it consistent with the LASSO model below
lr_spec <- logistic_reg(penalty = 0, mixture = 0) %>%
  set_engine("glmnet") %>%
  set_mode("classification")

lr_workflow <- workflow() %>%
  add_recipe(albatross_recipe) %>%
  add_model(lr_spec)

# Evaluate via cross-validation

Model 3: Random Forest

# Random Forest with tunable mtry and min_n
rf_spec <- rand_forest(
  mtry  = tune(),   # predictors randomly sampled at each split
  trees = 500,      # fixed number of trees (more = more stable estimates)
  min_n = tune()    # minimum observations required in a terminal node
) %>%
  set_engine("ranger", importance = "impurity", seed = rngseed) %>%  # impurity-based VIP
  set_mode("classification")

rf_workflow <- workflow() %>%
  add_recipe(albatross_recipe) %>%
  add_model(rf_spec)

# Grid of mtry (1 to 4, matching our predictor count) and min_n values
rf_grid <- grid_regular(
  mtry(range  = c(1, 4)),
  min_n(range = c(5, 40)),
  levels = 4
)

# Tune using CV
set.seed(rngseed)
rf_tune_results <- tune_grid(
  rf_workflow,
  resamples = cv_folds,
  grid      = rf_grid,
  metrics   = metric_set(roc_auc, accuracy),
  control   = control_grid(save_pred = TRUE)

Discussion

In this analysis, I examined whether season, latitude, wind speed class, and sea state class could predict the presence of Wandering Albatross during a 10-minute ship survey. The results showed that these environmental variables were moderately informative, and that Random Forest performed better than both standard logistic regression and LASSO logistic regression in cross-validation and on the held-out test set. This suggests that the relationship between environmental conditions and albatross presence may be more complex than a simple linear pattern.

The exploratory analysis also showed clear differences in albatross presence across seasons, latitudes, wind classes, and sea states. Wandering Albatross sightings were more common in spring and winter, at more southern latitudes, and under rougher wind and sea conditions. However, predictive performance was still imperfect, which means these variables help explain albatross presence but do not fully determine it. However, predictive performance was still imperfect, meaning these variables help explain albatross presence but do not fully determine it, and additional variables such as oceanographic features would likely be needed to further improve predictive accuracy.
